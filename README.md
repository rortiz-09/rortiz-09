## About Me

I work at the intersection of infrastructure operations, cloud governance, automation and monitoring. My current focus is building reliable platform foundations where NetBox acts as the source of truth, Zabbix provides operational visibility, Ansible automates configuration and validation, and Terraform supports repeatable infrastructure provisioning.

I enjoy turning operational complexity into systems that can be audited, repeated and improved by a team.

## Current Focus

- Platform leadership for hybrid infrastructure across on-premises, virtualization and cloud.
- Infrastructure automation with Ansible, Terraform and Git-based workflows.
- NetBox-driven inventory and data quality for servers, virtual machines, IPAM and ownership.
- Zabbix observability for service health, infrastructure changes and executive reporting.
- AWS cost, security and network posture reviews.
- Internal PKI and certificate lifecycle for trusted internal services.
